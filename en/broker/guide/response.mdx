---
title: "Response format"
description: "Understand Broker REST API success and error responses."
---

The Broker REST API uses HTTP status codes to indicate request results. Successful responses return the data defined by the operation directly, without a common `code`, `message`, or `data` envelope. Failed responses use a consistent `error` field.

## Successful responses

A successful request returns a `2xx` HTTP status code. The response body follows the schema declared on the operation page.

<Note>
Creating a transfer normally returns HTTP `201`; an accepted asynchronous transfer returns HTTP `202`. Other successful requests normally return HTTP `200`.
</Note>

## Error responses

Failed requests return the corresponding `4xx` or `5xx` HTTP status code and a consistent JSON body:

```json
{
  "error": "invalid request"
}
```

See [Pagination](/en/broker/guide/pagination) for pagination parameters and response formats. See [Error codes](/en/broker/guide/errors) for error status codes and recommended handling.
