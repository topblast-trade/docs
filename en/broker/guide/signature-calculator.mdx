Enter the App ID, App Secret, and request parameters to calculate `x-signature`. The calculation runs only in your browser; inputs are not sent to a server or saved locally.

<Warning>
Do not use a production App Secret on a shared device. Close the page after calculation to prevent others from viewing sensitive information.
</Warning>

## Calculation rules

The calculator concatenates the signature payload in this order:

```text
Timestamp + Method + Path + [?Query] + Body
```

- Query order and encoding must exactly match the final request.
- Body must exactly match the raw JSON string sent, including whitespace and line breaks.
- Refresh the timestamp and recalculate after changing any request parameter.
