<Note>
A transfer may complete asynchronously. Business code `20201` means the order remains `PROCESSING`; it is not a failure. Wait for [`broker.transferred`](/en/broker/api-reference/webhooks/broker-transferred), or query transfer detail with the same `txnId`. Do not retry with a new `txnId`.
</Note>
