<Note>
A transfer may complete asynchronously. HTTP `202 Accepted` means the request was accepted while the transfer remains `PROCESSING`; it is not a failure. Wait for [`broker.transferred`](/en/broker/api-reference/webhooks/broker-transferred), or call the detail operation with the same `txnId` from the create request (as `{transferId}`). Do not retry with a new `txnId`.
</Note>
