---
title: "Disable market"
openapi: "/openapi/b/openapi.en.json PATCH /v1/broker/events/{eventSlug}/markets/{marketId}"
---

Set `enabled` to `false` to disable the market:

```json
{
  "enabled": false
}
```

Enabling and disabling use the same market update operation; do not call a `/disable` subpath.
