---
title: "Authentication overview"
---

zpm separates its APIs into Broker APIs and User APIs. Each API type uses a different credential and authentication method.

| API type | Caller | Authentication |
| :--- | :--- | :--- |
| Broker APIs | Brokers, partners, and internal services | API key + timestamp + HMAC-SHA256 signature |
| User APIs | Authenticated end users | Bearer token |

- [Broker API authentication](/en/guide/authentication-b)
- [User API authentication](/en/guide/authentication-c)
