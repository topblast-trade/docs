The debugger includes the current 28 Broker REST API operations. Select an operation, complete its Path, Query, and Body, then click **Send** to generate the timestamp and HMAC-SHA256 signature and send the request.

<Warning>The debugger includes default test credentials. Saved credentials are stored in your browser. Never save production credentials on a shared device.</Warning>

<Note>Requests use Mintlify's same-origin proxy. The SK is used only for local signature calculation and is never sent to Mintlify or the API gateway.</Note>
