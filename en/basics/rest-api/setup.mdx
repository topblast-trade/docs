## Prerequisites

Choose the caller type and obtain the corresponding credentials:

- **Broker server**: Request a broker-level `API Key` and `API Secret` from topblast.
- **Web or mobile client**: Obtain an access token through the user login flow.
- **Trusted server-side bot or trading program**: Request a user-level `API Key` and `API Secret`.

<Warning>
Store the API Secret only on a trusted server. Never embed it in a Web, mobile, or other end-user client.
</Warning>

## Trading REST API endpoint

The Trading REST API provides one endpoint:

```text
https://api-test.topblast.trade
```

All requests must use HTTPS. Append a path from the Trading API Reference to this endpoint to form the complete request URL.

## Authentication

<Tabs>
  <Tab title="Broker REST API">
    Broker REST API requests use an API key and an HMAC-SHA256 signature. Include these headers with every request:

    <ParamField header="x-api-key" type="string" example="ba11_xxxxxxxxxxxxxxxxxxxxxxxx" required>
      API key assigned to the broker or partner by topblast.
    </ParamField>

    <ParamField header="x-timestamp" type="string" example="1752710400000" required>
      Unix request timestamp in seconds or milliseconds.
    </ParamField>

    <ParamField header="x-signature" type="string" example="Base64EncodedHmacSha256Signature" required>
      Base64-encoded HMAC-SHA256 request signature calculated with the API Secret.
    </ParamField>

    The signature payload is `Timestamp + Method + Path + [?Query] + Body`. See [Broker REST API authentication](/en/broker/guide/authentication) for details.
  </Tab>

  <Tab title="Trading REST API">
    Trading REST API requests support Bearer token or API Key authentication. Web and mobile clients use Bearer tokens. Trusted server-side bots and trading programs can use API Key authentication.

    <ParamField header="Authorization" type="string" example="Bearer &lt;access_token&gt;" required>
      Bearer token issued by the user login flow.
    </ParamField>

    Never send the token in a query parameter or request body. API Key authentication uses the same HMAC-SHA256 signing rules as the Broker REST API. See [Trading REST API authentication](/en/user/guide/authentication) for details.
  </Tab>
</Tabs>

## Examples

<Tabs>
  <Tab title="Broker REST API">
    ```bash
    curl --request GET \
      --url "https://api-test.topblast.trade/v1/broker/users?page=1&size=20" \
      --header "x-api-key: <broker_api_key>" \
      --header "x-timestamp: <timestamp>" \
      --header "x-signature: <signature>"
    ```

    <Info>
      Use the [signature calculator](/en/broker/guide/signature-calculator) to generate a signature, or send a test request with the [API debugger](/en/broker/guide/api-debugger).
    </Info>
  </Tab>

  <Tab title="Trading REST API">
    ```bash
    curl --request GET \
      --url "https://api-test.topblast.trade/v1/private/orders" \
      --header "Authorization: Bearer <access_token>" \
      --header "Content-Type: application/json"
    ```
  </Tab>
</Tabs>
