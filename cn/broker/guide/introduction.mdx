欢迎使用 Broker REST API。本文档面向通过服务端接入 topblast 交易平台的券商及合作方，介绍签名鉴权、业务接入流程和接口能力。

## 接口能力

完成接入后，券商服务端可以使用 Broker REST API 管理以下业务：

1. **用户管理**：建立券商用户与 topblast 用户的映射，同步登录 Token 和登出状态，更新用户信息，创建特殊账户，并查询券商名下的用户列表。
2. **资产管理**：为券商用户发起充值或提现，查询划转列表和划转详情，并查看用户资产及余额信息。
3. **交易管理**：查询券商用户的成交记录、仓位和当前委托，并执行撤单、平仓等交易操作。
4. **报表分析**：查询汇总报表、趋势报表、每日业务汇总和仪表盘数据，了解用户增长、活跃情况、资金流动及成交规模。
5. **事件管理**：查询平台事件及其市场信息，按券商业务需要启用或停用事件和单个市场，控制可运营范围。
6. **风控管理**：查询风控策略和风险敞口，读取或保存全局及事件级风控配置，控制最大最坏情况赔付额等风险指标。
7. **Webhooks**：通过统一的回调地址订阅券商业务事件，并在应用程序中处理状态变化。

所有接口均位于 `/v1/broker/*` 路径下，只能由券商服务端调用。请求通过 API Key、时间戳和 HMAC-SHA256 签名完成身份验证，并且只能访问当前券商权限范围内的数据。

<Warning>
请仅在券商服务端保存 API Secret。不要将 API Secret 暴露给浏览器、移动客户端或终端用户。
</Warning>

## 接入前准备

开始联调前，请向 topblast 获取券商级 `API Key` 和 `API Secret`，并确认已开通测试环境访问权限。

所有 Broker REST API 请求都必须携带以下 Header：

- `x-api-key`
- `x-timestamp`
- `x-signature`

签名规则和代码示例请参阅[授权签名](/cn/broker/guide/authentication)。

## 用户接入流程

券商用户登录成功后，券商服务端调用 `POST /v1/broker/tokens`，将券商侧用户 ID 和 Token 同步到 topblast。如果用户映射不存在，topblast 会在同步过程中自动创建。

```mermaid
sequenceDiagram
    autonumber

    participant BrokerClient as Broker 客户端
    participant BrokerServer as Broker 服务端
    participant Gateway as topblast 网关
    participant Core as topblast 核心交易

    rect rgb(239, 246, 255)
        Note over BrokerClient,Core: 阶段一：登录与用户映射

        BrokerClient->>BrokerServer: 用户登录
        BrokerServer->>BrokerServer: 分配Token
        BrokerServer->>Gateway: 同步用户信息和 Token
        activate Gateway
        Gateway->>Gateway: AK/SK 鉴权
        Gateway->>Core: 建立用户映射关系
        activate Core
        Core-->>Gateway: 返回用户信息
        deactivate Core
        Gateway-->>BrokerServer: 返回同步结果
        deactivate Gateway
        BrokerServer-->>BrokerClient: 返回登录结果
    end

    rect rgb(240, 253, 244)
        Note over BrokerClient,Core: 阶段二：后续业务请求

        BrokerClient->>Gateway: 携带 APIKey 和 Token 发起业务请求
        activate Gateway
        Gateway->>Gateway: Token 鉴权
        Gateway->>Core: 转发业务请求
        activate Core
        Core-->>Gateway: 返回业务结果
        deactivate Core
        Gateway-->>BrokerClient: 返回业务结果
        deactivate Gateway
    end
```
