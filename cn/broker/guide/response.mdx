---
title: "响应结构"
description: "了解 Broker REST API 的成功响应和统一错误响应。"
---

Broker REST API 使用 HTTP 状态码表示请求处理结果。成功响应直接返回接口定义的数据，不再统一包裹 `code`、`message` 或 `data`；失败响应统一返回 `error` 字段。

## 成功响应

成功请求返回 `2xx` HTTP 状态码，响应体以对应接口的 Schema 为准。

<Note>
创建划转成功时通常返回 HTTP `201`；如果请求已受理但仍在异步处理中，则返回 HTTP `202`。其他成功请求通常返回 HTTP `200`。
</Note>

## 失败响应

失败请求返回对应的 `4xx` 或 `5xx` HTTP 状态码，并使用统一 JSON 结构：

```json
{
  "error": "invalid request"
}
```

分页参数和分页响应格式请参阅[分页规则](/cn/broker/guide/pagination)。错误状态码和处理建议请参阅[错误代码](/cn/broker/guide/errors)。
