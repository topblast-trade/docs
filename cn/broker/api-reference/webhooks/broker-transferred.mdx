---
title: "broker.transferred"
description: "当券商用户资金划转完成时触发。"
openapi: "/openapi/b/webhooks.json webhook broker.transferred"
---

当资金划转进入最终状态时，平台向统一的 `webhookUrl` 发送 `broker.transferred`。通过 `data.state` 区分 `SUCCESS` 和 `FAILED`。

<Note>
平台采用至少一次投递语义。请使用 `eventId` 保证消费幂等，并在持久化事件后返回 `2xx`。
</Note>

签名验证、重试机制和接入步骤参见 [Webhooks](/cn/broker/guide/webhooks)。
