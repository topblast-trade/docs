---
title: "查询交易账户资金流水"
openapi: "/openapi/b/openapi.json GET /v1/broker/asset-histories"
---

接口暂未开放查询。读服务接入前，有效请求返回 HTTP 501。

省略 `user` 时，查询当前券商下全部交易账户的流水。传入 `user` 时，按平台用户 ID、券商用户 ID 或邮箱精确匹配单个账户。

流水按记录 ID 降序返回。`from` 查询 ID 大于该值的记录，`to` 查询 ID 小于该值的记录。读取更早的流水时，将当前批次最后一条记录的 `id` 用作下一次请求的 `to`，并保持其余筛选条件一致。成功响应直接返回数组。

`begin` 包含边界，`end` 排除边界。时间筛选优先使用业务时间 `eventTime`，缺失时使用入库时间 `recordedAt`。时间字段均为 Unix 毫秒。

金额以十进制字符串返回。冻结和解冻影响可用和锁定余额，同一序列的多条记录可能共享序列末余额。历史余额缺失时，余额字段为 `null`。
