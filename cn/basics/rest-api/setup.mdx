## 前置条件

开始前，请先确定调用方类型并获取对应凭证：

- **券商服务端**：向 topblast 申请券商级 `App ID` 和 `App Secret`。
- **Web、App 等用户客户端**：通过用户登录流程获取访问 Token。
- **量化程序、机器人等可信服务端**：申请用户级 `API Key` 和 `API Secret`。

<Warning>
App Secret 和用户 API Secret 只能保存在可信服务端。不要将它们写入 Web、App 或其他面向终端用户的客户端。
</Warning>

## REST API 端点

REST API 提供以下端点：

```text
https://api-test.topblast.trade
```

所有请求必须使用 HTTPS。将 API Reference 中的接口 Path 拼接到该端点后，即可得到完整请求地址。

## WebSocket 端点

WebSocket 提供以下端点：

```text
wss://ws-test.topblast.trade
```

使用 WebSocket 业务时，将 API Reference 中对应接口的 Path 拼接到该端点后，即可得到完整连接地址。

## 鉴权

<Tabs>
  <Tab title="Broker REST API">
    Broker REST API 使用 App ID 和 HMAC-SHA256 请求签名。每个请求必须包含以下 Header：

    <ParamField header="x-app-id" type="string" example="ba11_xxxxxxxxxxxxxxxxxxxxxxxx" required>
      topblast 分配给券商或合作方的 App ID。
    </ParamField>

    <ParamField header="x-timestamp" type="string" example="1752710400000" required>
      请求时间戳，支持 Unix 秒或毫秒时间戳。
    </ParamField>

    <ParamField header="x-signature" type="string" example="Base64EncodedHmacSha256Signature" required>
      使用 App Secret 计算并经过 Base64 编码的 HMAC-SHA256 请求签名。
    </ParamField>

    签名原文为 `Timestamp + Method + Path + [?Query] + Body`。详细规则请参阅[Broker REST API 鉴权](/cn/broker/guide/authentication)。
  </Tab>

  <Tab title="Trading REST API">
    所有 Trading REST API 请求都必须携带 `x-app-id`，用于标识请求所属券商。`/v1/public/*` 接口不需要用户鉴权；`/v1/private/*` 接口支持 Bearer Token 或 API Key 鉴权。Web、App 使用 Bearer Token；量化程序、机器人等可信服务端可以使用 API Key 鉴权。

    <ParamField header="x-app-id" type="string" example="ba11_xxxxxxxxxxxxxxxxxxxxxxxx" required>
      topblast 分配给券商或合作方的 App ID。
    </ParamField>

    <ParamField header="Authorization" type="string" example="Bearer &lt;access_token&gt;">
      私有接口使用的 Bearer Token。Token 由用户登录流程签发。
    </ParamField>

    不要通过查询参数或请求体传递 Token。API Key 鉴权采用与 Broker REST API 相同的 HMAC-SHA256 签名规则。详细说明请参阅[Trading REST API 鉴权](/cn/user/guide/authentication)。
  </Tab>
</Tabs>

## 请求示例

<Tabs>
  <Tab title="Broker REST API">
    ```bash
    curl --request GET \
      --url "https://api-test.topblast.trade/v1/broker/users?page=1&size=20" \
      --header "x-app-id: <broker_app_id>" \
      --header "x-timestamp: <timestamp>" \
      --header "x-signature: <signature>"
    ```

    <Info>
      你可以使用[签名计算器](/cn/broker/guide/signature-calculator)生成签名，或使用 [API 调试器](/cn/broker/guide/api-debugger)直接发送测试请求。
    </Info>
  </Tab>

  <Tab title="Trading REST API">
    ```bash
    curl --request GET \
      --url "https://api-test.topblast.trade/v1/private/orders" \
      --header "x-app-id: <broker_app_id>" \
      --header "Authorization: Bearer <access_token>" \
      --header "Content-Type: application/json"
    ```
  </Tab>
</Tabs>
