## 前置条件

开始前，请先确定调用方类型并获取对应凭证：

- **券商服务端**：向 topblast 申请券商级 `API Key` 和 `API Secret`。
- **Web、App 等用户客户端**：通过用户登录流程获取访问 Token。

<Warning>
API Secret 只能保存在券商服务端。不要将其写入 Web、App 或其他面向终端用户的客户端。
</Warning>

## Base URL

以下示例默认使用生产环境：

```text
https://api.topblast.trade
```

| 环境 | Base URL | 状态 |
| :--- | :--- | :--- |
| 开发环境 | `https://api-dev.topblast.trade` | 内部开发 |
| 测试环境 | `https://api-test.topblast.trade` | 推荐用于联调 |
| 生产环境 | `https://api.topblast.trade` | 正式环境 |

所有请求必须使用 HTTPS。将 API Reference 中的接口 Path 拼接到 Base URL 后即可得到完整请求地址。

## 鉴权

<Tabs>
  <Tab title="Broker REST API">
    Broker REST API 使用 API Key 和 HMAC-SHA256 请求签名。每个请求必须包含以下 Header：

    <ParamField header="x-api-key" type="string" example="ba11_xxxxxxxxxxxxxxxxxxxxxxxx" required>
      topblast 分配给券商或合作方的 API Key。
    </ParamField>

    <ParamField header="x-timestamp" type="string" example="1752710400000" required>
      请求时间戳，支持 Unix 秒或毫秒时间戳。
    </ParamField>

    <ParamField header="x-signature" type="string" example="Base64EncodedHmacSha256Signature" required>
      使用 API Secret 计算并经过 Base64 编码的 HMAC-SHA256 请求签名。
    </ParamField>

    签名原文为 `Timestamp + Method + Path + [?Query] + Body`。详细规则请参阅[Broker REST API 鉴权](/cn/broker/guide/authentication)。
  </Tab>

  <Tab title="Trading REST API">
    Trading REST API 使用 Bearer Token 识别当前登录用户。

    <ParamField header="Authorization" type="string" example="Bearer &lt;access_token&gt;" required>
      Bearer Token。Token 由用户登录流程签发。
    </ParamField>

    不要通过查询参数或请求体传递 Token。详细说明请参阅[Trading REST API 鉴权](/cn/user/guide/authentication)。
  </Tab>
</Tabs>

## 请求示例

<Tabs>
  <Tab title="Broker REST API">
    ```bash
    curl --request GET \
      --url "https://api.topblast.trade/api/v1/broker/user/users?page=1&pageSize=20" \
      --header "x-api-key: <broker_api_key>" \
      --header "x-timestamp: <timestamp>" \
      --header "x-signature: <signature>"
    ```

    <Info>
      你可以使用[签名计算器](/cn/broker/guide/signature-calculator)生成签名，或使用 [API 调试器](/cn/broker/guide/api-debugger)直接发送测试请求。
    </Info>
  </Tab>

  <Tab title="Trading REST API">
    ```bash
    curl --request GET \
      --url "https://api.topblast.trade/api/v2/private/orders" \
      --header "Authorization: Bearer <access_token>" \
      --header "Content-Type: application/json"
    ```
  </Tab>
</Tabs>
