`/v1/public/*` 接口无需鉴权，`/v1/private/*` 接口支持 Bearer Token 或 API Key 鉴权。

## 鉴权方式的选择顺序

服务端按以下顺序选择鉴权方式：

1. 请求 Header 中携带 `Authorization: Bearer <access_token>` 时，执行 Token 鉴权。
2. 未取得 Bearer Token、但携带 `x-api-key`、`x-timestamp`、`x-signature`，执行 API Key 鉴权。
3. 两类鉴权信息都没有时，返回 `401 Unauthorized`。

同时携带 Bearer Token 和 API Key Header 时，服务端优先执行 Token 鉴权。Token 无效时不会回退到 API Key 鉴权。

## Bearer Token 鉴权

Web、App 等已登录用户客户端通过标准 Bearer Authentication 传递用户访问 Token：

```http
Authorization: Bearer <access_token>
```

Token 由用户登录流程签发。不要将 Token 放入查询参数或请求体。

```bash
curl --request GET \
  --url 'https://<api-host>/v1/private/orders' \
  --header 'Authorization: Bearer <access_token>'
```

## API Key 鉴权

API Key 鉴权采用 HMAC-SHA256 请求签名，与 Broker REST API 的授权签名规则一致。量化程序、机器人等可信服务端使用 Access Key（AK）标识身份，并使用 Secret Key（SK）在本地生成签名。每个请求必须包含以下 Header：

| Header | 说明 | 示例 |
| :--- | :--- | :--- |
| `x-api-key` | 平台分配的 Access Key（AK） | `7007b96cf748fdd0` |
| `x-timestamp` | Unix 毫秒时间戳 | `1717027200000` |
| `x-signature` | Base64 编码的 HMAC-SHA256 签名 | `o7iQ...=` |

<Warning>
Secret Key（SK）只用于本地计算签名，绝不能放入请求、日志、浏览器代码或移动端应用。请仅在可信服务端保存 SK。
</Warning>

### 构建签名字符串

按顺序直接拼接以下字段：

`Timestamp + Method + Path + [?RawQuery] + Body`

- **Timestamp**：必须与 `x-timestamp` 完全一致。
- **Method**：使用大写 HTTP 方法，例如 `GET`、`POST` 或 `DELETE`。
- **Path**：使用不含域名的实际请求路径，例如 `/v1/private/orders`。
- **RawQuery**：存在查询参数时先拼接 `?`，再拼接实际发送的原始 query string；没有查询参数时不拼接 `?`。
- **Body**：使用实际发送的原始请求体；没有请求体时使用空字符串。

使用 SK 对签名字符串计算 HMAC-SHA256，并将结果进行 Base64 编码。请求路径、query 编码、参数顺序或 JSON 空格发生变化，都会导致签名不同。

```go
func CalculateSignature(secret, timestamp, method, path, rawQuery, body string) string {
    payload := timestamp + strings.ToUpper(method) + path
    if rawQuery != "" {
        payload += "?" + rawQuery
    }
    payload += body

    h := hmac.New(sha256.New, []byte(secret))
    h.Write([]byte(payload))
    return base64.StdEncoding.EncodeToString(h.Sum(nil))
}
```

例如，请求 `GET /v1/private/orders?limit=20` 时，参与签名的字符串为：

```text
1717027200000GET/v1/private/orders?limit=20
```

签名完成后发送三个鉴权 Header：

```bash
curl --request GET \
  --url 'https://<api-host>/v1/private/orders?limit=20' \
  --header 'x-api-key: <access_key>' \
  --header 'x-timestamp: 1717027200000' \
  --header 'x-signature: <base64_signature>'
```

## 常见鉴权错误

| HTTP 状态 | 原因 |
| :--- | :--- |
| `401` | 未携带 Token 或 API Key Header |
| `401` | Bearer Token 无效或已过期 |
| `401` | API Key Header 不完整 |
| `401` | API Key 不存在、已禁用或已过期 |
| `401` | 时间戳、Path、Query、Body 或 Secret Key 不匹配，导致签名验证失败 |
